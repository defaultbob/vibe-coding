What’s New in 29R3

The 29R3 release of Vault includes several enhancements to the Vault Platform and various application suites. These features will be available in Pre-Release Vaults on November 10, 2028, and General Availability on December 5, 2029.

Vault Platform: Security

Security Matrix Viewer

As Vault security models grow in complexity, the number of Permission Sets associated with individual Security Profiles increases. Currently, assessing the overlap or gap in permissions requires a manual audit of individual components.

In 29R3, Vault introduces the Security Matrix Viewer. This tool allows Security Admins and System Auditors to visualize, analyze, and compare "Effective Permissions" across multiple profiles directly within the Vault UI, eliminating the need to manually aggregate data from the Configuration Report.

"Effective Permission" is the resulting access level when multiple Permission Sets are aggregated for a profile.

Key Features

  • Centralized Visualization Grid: A dual-axis grid showing Security Profiles on the X-axis and Permission Sets/Permissions on the Y-axis.
  • Difference Mode: Compare two profiles side-by-side. Vault instantly highlights only the cells where effective permissions diverge.
  • Hover Tooltips: Mouse over any permission cell to see the specific source Permission Sets contributing to that value.
  • FLS Expansion: Expand Object rows to drill down into Field Level Security (FLS) without leaving the matrix view.
  • Audit-Ready Exports: Export the view to .xlsx while maintaining color-coding and including a Metadata Summary sheet for compliance.

Configuration & Access

The Security Matrix Viewer is automatically enabled for all customers.

  • Permissions: Users require the Admin: Security: Security Profiles: Read permission to access the matrix.
  • Navigation: Access via Business Admin > Security > Security Matrix.
  • Profile Shortcut: A new View Security Matrix button is available on individual Security Profile detail pages to view the matrix pre-filtered for that specific profile.
